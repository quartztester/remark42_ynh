Remark42 is a self-hosted comment system you embed on your own websites. It offers a lightweight, fast widget with no external dependencies, and stores everything in a local BoltDB file.

Built-in login methods: email magic link (through YunoHost's mail server), anonymous nicknames, and optional GitHub/Google OAuth configured in the app's config panel. The YunoHost admin account selected at install gets admin rights automatically: log in on the remark42 page with the Email provider and click the link sent to your inbox.

To add comments to a page, paste the embed snippet documented at https://remark42.com/docs/getting-started/installation/ pointing at this app's URL.
