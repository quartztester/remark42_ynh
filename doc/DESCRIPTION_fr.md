Remark42 est un système de commentaires auto-hébergé à intégrer dans vos propres sites. Il fournit un widget léger et rapide, sans dépendance externe, et stocke tout dans une base BoltDB locale.

Méthodes de connexion intégrées : lien magique par e-mail (via le serveur mail de YunoHost), pseudonymes anonymes, et OAuth GitHub/Google optionnel configuré dans le panneau de configuration. Le compte administrateur YunoHost choisi à l'installation reçoit automatiquement les droits d'administration : connectez-vous avec le fournisseur Email puis cliquez sur le lien reçu par mail.

Pour ajouter les commentaires à une page, collez le code d'intégration décrit sur https://remark42.com/docs/getting-started/installation/ en pointant vers l'URL de cette application.
