Remark42 est un système de commentaires auto-hébergé, léger et sans dépendance externe, à intégrer dans vos propres sites.

**Version livrée :** 1.17.1

## Caractéristiques

- Widget léger et rapide, stockage BoltDB local
- Connexion par lien magique e-mail (via le serveur mail YunoHost), pseudonymes anonymes, OAuth optionnel
- L'admin YunoHost choisi à l'installation reçoit les droits d'administration
